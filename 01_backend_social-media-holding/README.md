# Social Media Holding - API для работы с продуктами iPhone

## Описание задачи
Реализация API для CRUD-операций с продуктами iPhone, используя данные из dummyjson.com.

## Технологии
- Python 3.11
- FastAPI
- PostgreSQL
- SQLAlchemy
- Docker
- flake8, isort
