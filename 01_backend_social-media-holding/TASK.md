# Тестовое задание: API для CRUD-операций

## Компания: Social Media Holding
**Уровень:** Python разработчик

## Описание задания
Реализовать API для CRUD-операций с продуктами "iPhone", используя данные из dummyjson.com.

## Источник данных
- API: https://dummyjson.com/docs/products
- Эндпоинт для продуктов: https://dummyjson.com/products

## Требования

### Функциональные требования
1. Создать API с следующими эндпоинтами:
   - Получение всех продуктов "iPhone"
   - Получение продукта по ID
   - Создание нового продукта
   - Обновление существующего продукта
   - Удаление продукта

2. Интеграция с dummyjson.com:
   - При запуске приложения загрузить все продукты "iPhone" из dummyjson
   - Сохранить их в локальную базу данных

### Технические требования
- Python 3.8+
- FastAPI/Django/Flask
- PostgreSQL (опционально)
- ORM (опционально)
