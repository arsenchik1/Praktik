# Задание: Конвертер валют (Backend)

## Описание
Разработать REST API для конвертации валют с использованием внешнего API.

## Требования к заданию
1. **API должно уметь:**
   - Получать актуальные курсы валют с внешнего API
   - Конвертировать сумму из одной валюты в другую
   - Отдавать список доступных валют
   - Сохранять историю конвертаций (опционально)

2. **Технические требования:**
   - Python + FastAPI/Flask/Django
   - PostgreSQL для хранения данных
   - Кэширование курсов (чтобы не дёргать внешнее API каждый раз)
   - Docker контейнеризация
   - Документация OpenAPI (Swagger)

3. **Функциональность:**
   - Эндпоинт для получения курсов: GET /api/rates?base=USD
   - Эндпоинт для конвертации: POST /api/convert
   - Эндпоинт для списка валют: GET /api/currencies
