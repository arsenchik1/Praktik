# Задание: Frontend + GraphQL

## Описание задания
Создайте single page application, работающий с Github GraphQL API. 
Приложение представляет из себя «менеджер» для работы с issues на гитхабе.

## Функциональные требования
1. **Стартовый экран** - поле для ввода названия репозитория (формат: "owner/repo")
2. **Список issues** - после выбора репозитория отображаются все открытые issues:
   - Название issue
   - Текст issue
   - Количество комментариев
3. **Добавление комментария** - для каждого issue форма добавления комментария

## Технологии
- React
- Apollo Client (GraphQL)
- GitHub GraphQL API

## Требования к реализации
- Интеграция с GitHub GraphQL API
- Обработка loading состояний
- Валидация ввода
- Адаптивный дизайн
- Обработка ошибок
