# Интеграция с 1С для получения данных о сотрудниках

## Описание задачи
Сервис для интеграции с внешней учетной системой 1С для получения списка сотрудников. Реализован асинхронный API endpoint `/team/get_employees`, который получает данные из 1С, преобразует их и возвращает в требуемом формате.

## Технологии
- **Python 3.11**
- **Django 4.2** (асинхронный режим)
- **PostgreSQL 15**
- **Docker & Docker Compose**
- **aiohttp** для асинхронных HTTP запросов
- **python-decouple** для управления конфигурацией
