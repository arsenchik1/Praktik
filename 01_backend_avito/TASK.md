# Тестовое задание: URL Shortener (Avito)

## Задача
Разработать HTTP сервис для сокращения URL наподобие Bitly.

## Функциональные требования
- Создание короткой ссылки из длинного URL
- Редирект с короткой ссылки на оригинальный URL
- Кастомные ссылки (пользователь может задать свой вариант)
- Валидация URL

## Технические требования
- Язык: Python
- Фреймворк: FastAPI
- База данных: PostgreSQL
- Контейнеризация: Docker + docker-compose

## Выполненные требования
- ✅ Тесты с покрытием >70%
- ✅ Валидация URL
- ✅ Кастомные ссылки
- ✅ Docker контейнеризация
