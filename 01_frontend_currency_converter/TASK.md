# Задание: Конвертер валют (Frontend SPA)

## Описание
Напишите SPA для конвертирования валют. Для получения текущих курсов используйте любое открытое API.

## Обязательные требования

### Страница 1: Конвертер
- [x] Текстовое поле для ввода в формате "15 usd in rub"
- [x] Поле для ввода суммы
- [x] Выбор исходной валюты
- [x] Выбор целевой валюты
- [x] Отображение результата конвертации
- [x] Обработка текстового ввода (парсинг строки)

### Страница 2: Текущие курсы
- [x] Таблица с курсами всех валют
- [x] Возможность выбора базовой валюты
- [x] Автоопределение валюты пользователя
- [x] "Свежие" курсы (актуальные на момент запроса)

### Технические требования
- [x] Адаптивный дизайн (работает на мобильных)
- [x] Работает в браузере без дополнительных установок
- [x] Использование открытого API
- [x] Обработка ошибок сети/API
- [x] Индикация загрузки

## Дополнительные плюсы (реализовано)
- [x] Хорошо продуманный интерфейс и внешний вид
- [ ] Тесты (можно добавить Jest)
- [x] Максимальная скорость работы
- [x] Анимации переходов
- [x] Кэширование результатов
- [x] Автоопределение базовой валюты

## Используемые технологии
- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (ES6+)
- Fetch API
- ExchangeRate-API

- [x] Качество кода
- [x] Интерфейс и UX

- [x] Соответствие требованиям
