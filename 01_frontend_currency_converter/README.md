# Конвертер валют (Frontend SPA)

## Описание проекта
Одностраничное приложение (SPA) для конвертации валют с использованием открытого API.

## Технологии
- HTML5
- CSS3 (Flexbox, Grid, Анимации)
- JavaScript (ES6+)
- API: exchangerate-api.com
- Адаптивный дизайн

## Функциональность

### Страница 1: Конвертер
- ✅ Поле для ввода суммы
- ✅ Выбор валюты из списка
- ✅ Кнопка для свапа валют
- ✅ Текстовое поле для ввода в формате "15 usd in rub"
- ✅ Мгновенная конвертация
- ✅ Отображение курса конвертации

### Страница 2: Курсы валют
- ✅ Таблица со всеми валютами
- ✅ Выбор базовой валюты
- ✅ Автоматическое обновление курсов
- ✅ Время последнего обновления

### Дополнительные функции
- ✅ Автоопределение валюты пользователя
- ✅ Адаптивный дизайн для мобильных
- ✅ Анимации переходов
- ✅ Обработка ошибок
- ✅ Индикатор загрузки
