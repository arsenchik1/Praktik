# Тестовое задание: Форма регистрации с AJAX

## Описание задания
Создать страницу с формой регистрации, которая отправляется через AJAX.

### Требования к форме:
- Имя
- Фамилия
- Email
- Пароль
- Повтор пароля

### Функциональные требования:
1. Отправка формы через AJAX
2. Валидация на сервере:
   - Email содержит @
   - Пароли совпадают
3. Проверка существующего пользователя в массиве
4. Логирование результатов проверки
5. Соответствующий UI/UX с Bootstrap

### Технологии:
- Python (Flask)
- Bootstrap 5
- JavaScript (Fetch API)
- PostgreSQL (SQLAlchemy ORM)
