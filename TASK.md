# Тестовое задание: Интеграция с 1С для получения данных сотрудников

## Задача
Разработать сервис на Django 3+ для интеграции с внешней учетной системой 1С, который будет получать данные о сотрудниках и предоставлять их через REST API.

## Требования
- Реализовать API endpoint: GET /team/get_employees
- Интеграция с внешней системой 1С (получение списка сотрудников)
- Преобразование данных из формата 1С в требуемый формат ответа
- Асинхронная обработка запросов
- Настраиваемые параметры подключения (ClubId, login, password, ссылка)

## Формат ответа
{
    "id": "идентификатор сотрудника",
    "name": "имя сотрудника",
    "last_name": "фамилия сотрудника",
    "phone": "телефон сотрудника",
    "image_url": "аватар сотрудника"
}
