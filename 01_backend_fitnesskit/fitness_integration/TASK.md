# Тестовое задание: Интеграция с 1С (FitnessKit)

## Описание задачи
Необходимо разработать сервис на Django 3+, который интегрируется с внешней учетной системой 1С для получения данных о сотрудниках.

## Требования
1. Реализовать API эндпоинт: `GET /team/get_employees`
2. Интеграция с внешней системой 1С (получение списка сотрудников)
3. Асинхронная обработка запросов
4. Настраиваемые параметры подключения (ClubId, логин, пароль, ссылка)
5. Преобразование данных в требуемый формат

## Формат ответа
```json
{
    "employees": [
        {
            "id": "идентификатор",
            "name": "имя",
            "last_name": "фамилия",
            "phone": "телефон",
            "image_url": "ссылка на аватар"
        }
    ]
}
```

- Django 3.2+
